--- ANALYSIS ---

CVE-2018-4233 is **DEAD on PS5 14.10**.

The bug: DFG JIT didn't model side effects of CreateThis through a Proxy.
When new ProxyCtor(args) triggers the Proxy's 'prototype' getter, that getter
changes the argument's Structure. DFG's compiled code should have used stale
type assumptions → type confusion between doubles and JSValues.

On PS5 14.10: DFG correctly handles the Structure change. All 5 test variants
(direct Proxy, multiple attempts, Reflect.construct, call-warmed Victim) show
zero confusion across 70+ attempts total. DFG either:
  (a) Added clobberWorld to CreateThis (the official fix), or
  (b) Does an OSR exit when the Proxy is encountered

Either way, the exploit chain (addrof + fakeobj via type confusion) is
completely dead on 14.10.

Note: This is a DIFFERENT bug from CVE-2018-4416 (StructureID reuse) which
was already confirmed dead (p634). Both are 2018-era DFG bugs, both patched.
