## Attack surface and limits of conclusions

Pattern matching and optional clear-on-success interact with concurrent signal, clear and deletion. Verify helper locking and that its result semantics on failure match callers’ expectations. Fixed eight-byte copyout avoids a user-sized buffer allocation in this wrapper. Missing handle returns 3 and invalid arguments return 0x16.

This is static analysis of a recorded kernel image. A missing check in this body does not establish that the syscall entry path, object namespace, or external callees impose no checks. Review points are not confirmed vulnerabilities or exploit primitives. No target code was executed.
