## Behavior and data flow

At `0x705c60`, performs the same two-predicate credential gate as 533, allocates a 0x18-byte alias payload, and looks up the caller’s source descriptor with `0x72c3d0`. Requires source file type **0xe**; other types return 9 after releasing references. Uses BMI1 `ANDN` to enforce `(requested_flags & ~source_payload->allowed_flags) == 0`; added rights return 0xd. Copies the source’s one-byte special state, retains its VM object through `0x461b20`, atomically increments the shared backing region’s +0x20 reference, and drops the source file reference. Allocates a fresh descriptor/file, publishes the same fixed type/operations table as 533 using the alias payload, marks its descriptor-table entry under lock and returns the new integer descriptor via `td + 0x408`. Errors unwind retained VM and region references and free the payload.

## Dispatch and subcommands

No subcommands or indirect user dispatch. Requested flags form a rights subset rather than a numeric command. File type 0xe selects the expected payload layout. The fixed operations-table pointer is RVA 0x2202e88, whose actual entries are unavailable here.

## Permission checks and validation

Requires either credential predicate `0x6095c0` or `0x609620` to succeed. Source lookup uses the caller’s descriptor namespace; file type is checked before accessing its payload. Requested rights cannot exceed source rights, as shown by the `ANDN`/zero branch at 0x705d3a..0x705d48. Refcounts use atomic instructions; descriptor-table marking is locked. No direct creator-UID check is shown, but descriptor possession and the entry credential gate are visible restrictions.

Recovered helpers refine this gate: 0x6095c0 accepts credential capability-word +0x68 bit 62; 0x609620 accepts bit 61. Both also allow capability bit 56 when platform helper 0x5a4c20 succeeds, or identity high byte 0x41 when platform helper 0x5a59f0 succeeds. The platform helpers are external, so their policy is unresolved. The flag-0x4 accounting predicates additionally combine capability bits 61/62 with credential byte +0x82 bit 7.

## Attack surface and limits of conclusions

Audit descriptor lookup/close races, source rights attenuation, alias publication rollback and shared-region reference accounting. The rights-subset test prevents this body from simply granting arbitrary additional protection bits. Memory-object and region references are taken before releasing the source file. This handler accepts an integer descriptor and flag word, not a caller-supplied payload pointer. No arbitrary-read/write primitive is established.

This is static analysis of a recorded kernel image. A missing check in this body does not establish that the syscall entry path, object namespace, or external callees impose no checks. Review points are not confirmed vulnerabilities or exploit primitives. No target code was executed.
