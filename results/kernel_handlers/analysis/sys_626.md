## Interface and unresolved selector mapping

This five-argument root uses command32 +0, domain32 +8, index32 +0x10, first user output pointer +0x18, and second user output pointer +0x20. It first reads index and zeroes exactly 256 local bytes (two contiguous 0x80-byte buffers). It accepts unsigned command numbers **1..6**, otherwise returns **22**. At `0xffffffff8afc4e6d`, it jumps through the six signed offsets at **0xffffffff8c0e35bc**, with default status **6** preloaded.

The table lies outside supplied text/data ranges; numeric command-to-target mapping and the set of unsupported in-range commands are unknown. Branch semantics below are recovered from original runtime-address instructions, without inventing selector assignments.

## Register and copy dataflow

The direct MSR block at 0xffffffff8afc4f7e reads **0xc0010241+2*index** for index<=3 (implemented by OR, equivalent over that range), otherwise **0xc0010189+2*index**. EDX:EAX is combined into a full 64-bit local.

Nearby helper **0xffffffff8afc5000** reads **0xc0010231+2*index** and returns only the **low32 sign-extended to 64 bits**, a meaningful difference from the direct-read path. It locks current thread state, conditionally invokes `0xffffffff8b0777c0(td,8)` for domain1 when current CPU<8 or invokes it with 0 for domain2 when CPU>7, reads the register, restores through `0xffffffff8b077860` when needed, and unlocks `*(td+0)+0x18`. CPU binding/migration is an inference from the observed CPU tests and calls; no symbol is verified.

The 8-byte copy paths call `0xffffffff8b5da3e0(gs:0,0xffffffff8bd0f297,0)` before `0xffffffff8ac191d0(&value,user,8)`. Independent inspection of the latter validates destination arithmetic/user range and copies under STAC/CLAC. The two-buffer path uses helper **0xffffffff8afc3c50**; its nearby body calls the same copy routine with fixed **0x80** length and the same accounting-like prelude. The producer `0xffffffff8b33f9f0` is not assigned a named purpose.

## Checks, errors, and attack surface

There is no explicit credential predicate or td+0x408 write in the root. Default 6, guard failure 22, producer status, fixed-size copy statuses, and 8-byte copy status are distinguishable return paths. User memory checks are delegated to the inspected copy helper. The second-output 128-byte copy occurs before the first-output copy, so a later failure can leave one user buffer already modified.

The local buffers are initialized, and users select only fixed output addresses plus bounded register index/domain parameters, not arbitrary MSR numbers or kernel addresses. Nevertheless these are hardware-state reads and possibly an opaque hardware snapshot producer. Dispatcher-level policy and missing command mapping prevent a claim that any specific numeric command is unprivileged or dangerous. Stack-protector failure invokes `0xffffffff8b0bd6b0` then UD2.
