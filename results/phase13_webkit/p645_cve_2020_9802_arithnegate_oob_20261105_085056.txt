--- ANALYSIS ---

CVE-2020-9802 is **DEAD on PS5 14.10**.

The bug: DFG CSE treats ArithNegate as pure, but -INT_MIN overflows int32 to
double. If CSE replaces a second ArithNegate with the first's result, the second
use site may assume int32 → wrong index → OOB.

On PS5 14.10: DFG correctly handles ALL ArithNegate edge cases:
  - INT_MIN negation correctly produces double 2^31
  - |0 truncation correctly wraps to -2^31
  - Bounds checks NOT eliminated by range analysis
  - Math.abs(INT_MIN) correctly rejected
  - Negative zero handled without confusion
  - TypedArray bounds checks hold for all edge values
  - OSR-compiled hot loops handle INT_MIN correctly

Note: Section B ANOMALY was a false positive in the detection code.
ToInt32(2^31) = -2^31 is correct JS semantics, not a vulnerability.

Sony patched the CSE ArithNegate overflow or DFG range analysis handles it
correctly on the 605.1.15 branch.
