## Behavior and data flow

Looks up type 0x120, passes the signed low-32-bit value at argument +8 plus a kernel result pointer to `0xc15c20`, and releases the lookup. A nonzero helper status is returned immediately. On success, an optional user pointer at +0x10 receives four bytes of result; a null pointer still performs the operation and returns 0. Missing handle returns 3. Count validation/reset semantics are in the core helper, not in this wrapper.

Recovered reset helper rejects new_count greater than maximum; **any negative value restores the recorded initial count**. It resets current_count, snapshots waiter_count, unlinks all queued waiters, sets their cancellation status to 0x55 plus wake state, and broadcasts under lock. A closed/deleted object leaves count unchanged and returns an affected count of zero.

The state-changing operation precedes optional four-byte output, so an output fault does not undo it. List consistency assertions and wakeup/lifecycle synchronization remain review boundaries.
