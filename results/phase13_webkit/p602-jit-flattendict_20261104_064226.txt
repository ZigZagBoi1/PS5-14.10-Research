  1. Detect if JSC JIT (DFG/FTL) is active on PS5 14.10

CVE-2023-42917 ROOT CAUSE (from upstream WebKit commit b0a755e34426):
  Bug 265067: "Race condition between JSObject::getDirectConcurrently
  users and Structure::flattenDictionaryStructure"
  - flattenDictionaryStructure can shrink the butterfly
  - JIT compiler threads read butterfly via getDirectConcurrently
  - Missing cellLock before shrinking → stale butterfly pointer → UAF/OOB
  - Fix: compute capacity before/after, take cellLock if shrinking

=== ANALYSIS ===

  JIT is active but the race didn't trigger. Possible reasons:

  1. TIMING: Our probe mutates and reads from the SAME JS thread.
     The race is between the JIT COMPILER THREAD (internal JSC background
     thread) and the main thread. Single-threaded mutation+read doesn't
     create enough concurrency with the compiler.

  2. FLATTEN TRIGGER: Adding/deleting properties may not force
     flattenDictionaryStructure. More direct triggers:
     - Object.freeze() / Object.seal() / Object.preventExtensions()
     - These force structure transitions that flatten dictionaries

  3. ITERATION COUNT: Race conditions need millions of attempts.
     Our 50-200 iterations per round may be far too few.

  4. PATCHED: Sony may have cherry-picked this fix (high-profile
     in-the-wild zero-day from Dec 2023, PS5 14.10 build Sep 2026).
     However, they didn't backport FontFace UAF fixes from 2026,
     so cherry-picking a 2023 fix is uncertain.

  3. Run millions of iterations with staggered timing
  4. If race never triggers after exhaustive testing → likely patched
