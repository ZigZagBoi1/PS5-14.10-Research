## Behavior

Obtains an object through td->proc+0x48, locks object+0x40, compares its +0x10 pointer to global RVA 0x3e0b510, and stores the inequality result (0 or 1) in td+0x408. Unlocks and returns syscall status zero. This is consistent with an is-in-sandbox/root-directory query; the exact global symbol is not present.
