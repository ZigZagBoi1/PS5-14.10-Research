--- ANALYSIS ---

CVE-2019-8623/8671 is **DEAD on PS5 14.10**.

The bug: DFG LICM hoists loop-invariant computations. If a variable is only
assigned inside a dead branch, LICM may hoist the USE but not the ASSIGNMENT,
reading uninitialized stack data (stale JSValues, pointers → addrof primitive).

On PS5 14.10: DFG does NOT hoist uninitialized variable uses in ANY variant:
  - Dead branch (if i < 0): not hoisted
  - Object.is(-0, 0) trick: not hoisted
  - var reset pattern: not hoisted
  - Dead array access: not hoisted
  - Stack residue: not leaked
  - try-catch: not hoisted

All 6 sections returned `undefined` consistently. DFG LICM correctly tracks
variable initialization state and does not hoist uses past their definitions.

Sony backported the LICM initialization check to 605.1.15.
