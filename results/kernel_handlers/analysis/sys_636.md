## Behavior and layouts

Body `0xffffffff8b07e4d0`–`0xffffffff8b07e59c` reads pointer u64 at argument `+0` and count low u32 at `+8`. The caller's pointer at `+0x140` is passed to opaque predicate `0xffffffff8afc8f90`; zero returns 1. The exact credential or permission identity is unknown. The unsigned range idiom at `0xffffffff8b07e4f1`, `(uint32_t)(count - 513) < 0xfffffe00`, rejects every value except **1..512**, returning 22.

It calls `0xffffffff8b60bb20(0xffffffff8e2d5900,0,0,0)` (acquire-like), then `0xffffffff8b5da3e0(current,0xffffffff8bd57f3d,0)` and `0xffffffff8ac19280(input_pointer, 0xffffffff8e2d5920, (uint64_t)count << 4)`. Transfer direction is input-to-global by call dataflow; exact fault semantics remain unreviewed. On zero result, global u32 `0xffffffff8e2d7920=count`, followed by sort-like `0xffffffff8b35e490(global_table,count,16,0xffffffff8ac2ba00)`. Finally `0xffffffff8b60c4b0(0xffffffff8e2d5900,0,0)` runs and the transfer result is returned.

## Restrictions, returns and surface

There is no command dispatcher. The layout established in this body is an array of opaque 16-byte records, capacity 512, plus a global u32 count and a lock-like object. Exact record field meanings and comparator ordering are not established by this handler; `0xffffffff8ac2ba00` is a comparator argument address and must be followed before naming it. Numeric errors: 1 for predicate rejection, 22 for count rejection; transfer error propagates; zero on completed update.

The primary surface is an authority-gated replacement of shared global records with bounded input (16..8192 bytes), followed by sorting. On transfer failure, this wrapper does not explicitly restore partially written global bytes, although it also leaves the previous count unchanged; whether the transfer is partial on failure and whether consumers can observe changed bytes require callee review. This is a grounded review point, not a demonstrated vulnerability. No ordering validation or per-record validation is visible here.

## Additional direct-helper evidence

Separate read-only disassembly of supplied `kernel_text.bin` at `0xffffffff8afc8f90`–`0xffffffff8afc8fa0` establishes its exact predicate: return `(u64(authority + 0x60) >> 62) & 1`, i.e. test mask `0x4000000000000000`. Thus this wrapper's gate requires that bit in the object reached through caller `+0x140`. The field's exact symbolic permission name and authority-structure identity are not corroborated. These helper bytes are supplemental source-kernel evidence outside the selected-body ELF.
