All stores use RIP-relative global addresses and constants. No caller memory is accessed and no output pointer is used. The stores are ordinary non-LOCK writes in source order. ## Attack-surface observations and unresolved contracts

The observable side effect is global state reset. Follow-up would identify all writers/readers of the three globals and syscall-table routing permissions. The neighboring getter supports shared-state interpretation, but does not identify the subsystem or prove a race.

No exploitability finding is made. External helpers, unknown credential semantics, absent mutable data and upstream dispatcher behavior bound the conclusions. A missing check in this local slice is not proof of globally missing authorization. Static control flow does not prove any branch executed.
