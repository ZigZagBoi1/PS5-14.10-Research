=== THE CLOSING FACT ===

"Sony and the developers already patched the digital version of the game —
the exploit does not work if the game is updated OR acquired in digital
format."

The digital storefront serves a REBUILT base package: the ps2emu escape
fix is baked into the base build itself. Update-blocking (our serve.py
--blackhole-updates, gs2.ww.np.dl.playstation.net blackholed) protects the
INSTALLED base from patches — it cannot help when the base being served
is already patched.

=== WHY THERE IS NO WORKAROUND ===

1. The PS2-Classic line (PS2-on-PS4/PS5) was DIGITAL-ONLY: Star Wars
   Racer Revenge has no disc release. The "install base 1.00 from disc
   offline" route does not exist for this title.
2. Installing an archived pre-patch package requires a jailbroken console
   — the standard catch-22 on stock firmware.
3. The whole mast1c0re-family catalog (Okage: Shadow King, etc.) is
   digital-only and was rebuilt the same way when the technique went
   public — there is no unpatched sibling title to fall back to.
