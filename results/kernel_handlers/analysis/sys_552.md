## Behavior and data flow

Uses removal-oriented handle lookup with type 0x120. A missing handle returns 3; the role predicate must be nonzero or this returns 1 after releasing the record. Removes the handle, releases lookup, acquires registry context, decrements object +0x54, and releases context. If references remain, returns 0. Last reference invokes `0xc15dd0` then frees stored name and semaphore object.
