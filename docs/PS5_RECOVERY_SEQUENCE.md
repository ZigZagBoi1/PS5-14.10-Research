# PS5 Lua Loader Recovery Sequence

When the Lua loader on TCP 9026 stops responding:

1. **Esc** - opens screenshot overlay
2. **Down arrow** - hover home icon
3. **Right arrow** - hover app switcher
4. **Enter** - open app switcher
5. **Up arrow hold 4s** - ensure at top app
6. **Enter** - select the app
7. **Down arrow x2** - navigate to "close game"
8. **Enter** - close the game
9. Wait for home menu, **Enter once** - relaunch game + loader

Do NOT use timed button presses. Use screen recognition if automating.

If the game crashes (not loader down), spam Enter until the app reloads.
