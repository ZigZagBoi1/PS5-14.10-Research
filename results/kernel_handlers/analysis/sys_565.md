# Handler 565: Configure one of six performance event selectors

## Identity and scope

- First instruction: `jmp 0x6034e0`; next three bytes are `int3` padding.
- Sysent metadata: 3 arguments; mapping classification `real`.
- Runtime base from supplied context: `0xffffffff8a9c0000`; all addresses below are RVAs.
- Primary analyzed body (inclusive): 0x6034e0..0x603709.
- The full `.asm` covers all 4,096 source bytes, plus primary implementation and selected support. Neighbor trampoline targets are not part of this syscall.

## Behavior

Reads a selector, a uint32 slot index and a uint64 configuration. Index must be 0..5. Rejects values containing any bit from 0xfffffff0007b0000. If `(value & 0xf000000ff)` equals 0x100000070 or 0x6e, further masks with 0x0000000fff8400ff. Saves the result at PCB+0x160+8*index, ORing 0x10000 when disabled or 0x410000 when enabled. Enabled threads call 0x602d40 to apply the state.

## Dispatch and subcommands

The low 32-bit selector is interpreted by an unsigned `(selector-1) < 99999` test: 1..99999 means a process; zero means every thread of the current process; all other values are resolved as a thread ID within the current PID. This is a selector branch, not a jump table. The index selects a six-element data array; it is not a code-dispatch table.

## Permission and validation checks

The process-selector path calls 0x26d0a8 -> 0x609020 on caller td+0x140; the helper requires cred+0x58 == 0x4800000000010003. Failure returns 3 (ESRCH), hiding the operation. Process lookup 0x53c170 must succeed. The first target thread credential is passed to 0x609890; failure returns 1 (EPERM). The zero and current-process-thread paths contain no equivalent caller credential gate, but target lookup is scoped with the current PID. A missing thread returns 3. Invalid index or forbidden configuration bits return 22 (EINVAL) before target selection.

## Data flow and locking

uap+0 selector, +8 uint32 index, +0x10 uint64 config -> validation and event-specific mask -> locked target set -> one saved event-select slot per thread -> optional PMU update. There is no user-pointer dereference from the value argument.

## Attack surface and limits

Review PMU event-policy restrictions, the event-specific mask, cross-process policy and synchronization. Slot bounds are explicit. The supplied value is a register configuration, not an arbitrary address, and this handler does not supply evidence of arbitrary kernel writes or writable PTEs.

## Interpretation check

The words map to six fixed even-numbered MSRs in the 0xc0010200..0xc001020a bank via 0x602830. Prior PTE interpretations are contradicted by the hardware instructions.
