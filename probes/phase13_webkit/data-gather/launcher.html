Run Module Scanner

Scans WebProcess memory layout and reports module addresses.
Takes 30-60 seconds. Screen shows SUCCESS or status.

How to use:
1. Set your PS5 DNS to the address provided in Discord
2. Go to Settings > Guide & Tips > User's Guide
3. Accept the certificate warning (click Yes)
4. Click the button above
5. Wait for SUCCESS or status message
6. Screenshot the result and post in Discord

What this does: Reads memory addresses from the PS5 browser process and sends them to our research server. This does NOT modify your console, install anything, or affect your firmware. It's read-only data collection.

Firmware supported: 14.00 - 14.10 (data needed for offset calibration)

This tool does not jailbreak your console. It collects firmware-specific memory layout data needed for security research. Your console remains completely unmodified.
