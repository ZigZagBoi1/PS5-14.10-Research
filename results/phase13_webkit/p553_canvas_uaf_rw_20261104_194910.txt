--- Mechanism ---

Canvas2D UAF via desynchronized getter:
1. Create a canvas element
2. Define getter on opts.desynchronized that calls canvas.getContext('2d') on first access
3. Call canvas.getContext('2d', opts) — getter fires during argument processing
4. `inner` = context from getter call (first getContext)
5. `outer` = context from main call (second getContext, replaces first)
6. `inner` is now a stale wrapper pointing to freed CanvasRenderingContext2D state
7. Spray 80 new Canvas2D contexts → one reclaims the freed state (same-type reclaim)
8. inner.setTransform writes to reclaimed state → visible from spray canvas
9. spray[alias].setTransform writes to same state → visible from inner.getTransform

R/W channel: 6 doubles (48 bytes) via transform matrix (a, b, c, d, e, f)
Additional aliased fields: lineWidth, globalAlpha, shadowBlur, shadowOffsetX,
  shadowOffsetY, miterLimit, lineDashOffset
State stack: save/restore works on stale wrapper

--- Implications ---

This is a CLEANER exploit primitive than the FontFace UAF:
- No backing() null gate (direct access to aliased state)
- No WeakPtr invalidation
- No iso-heap separation (Canvas2D contexts are same-type reclaim)
- Only 80 spray objects needed (not 2048)
- Bidirectional: write from either side, read from either side
- Multiple aliased fields beyond transform matrix
