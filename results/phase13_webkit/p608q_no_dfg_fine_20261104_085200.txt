Crash thresholds converge:

All crash at ~20,200-20,350 dead resizable ArrayBuffers.
This is a PURE GC BUG — the resizable ArrayBuffer count is the sole variable.

Open question: Is this about the "resizable" flag in JSC's GC handling,
or simply memory pressure? Each resizable AB reserves maxByteLength (4KB)
capacity → 20K × 4KB = 80MB. Testing with non-resizable ABs of equal
size (p608r) will discriminate.
