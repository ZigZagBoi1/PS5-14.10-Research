## Permission checks and attack surface

The local boundary includes process-owned context lookup, handle/index validation, reference acceptance and request-state/waiter checks. Domain selection and feature helpers are not automatically permission checks; their broader policy meanings are unresolved. Review boundaries are repeated/stale IDs in one batch, transitions between the initial lookup and deletion reacquisition, completion versus waiter state, removal/free ordering, per-item failures after earlier deletions and final copyout failure. A failed final output copy does not roll back already applied deletions. Stack array sizes are bounded by128, rather than directly accepting an arbitrary count.

`0x3af8f0` and `0x3b1670` are separate disabled wrappers, while multi-wait/poll/cancel are neighboring active interfaces. Their code is retained as carrier context and is not a subcommand of delete.
