# Handler 587: Return full or filtered process credential metadata

## Behavior

Zeroes a 0x88-byte local record. PID zero selects the current process; nonzero PID is looked up and checked with 0x2a8ca0(td,target). Then privilege 0x2ae is checked. If allowed, copies 0x88 bytes starting at target_cred+0x58. On privilege failure, permits only a small authid allowlist and capabilities & 0x7000000000000000; remaining record bytes stay zero. After unlocking, a nonnull output pointer receives the 0x88-byte record and the copyout result becomes the return status.

## Dispatch and subcommands

PID zero is the current-process branch. Nonzero PID selects a process lookup path. No code dispatch table is in this handler. Filtering uses a bounded bit test: authid in {0x4800000010000004,0x4800000010000011,0x4800000010000012,0x4800000010000013}, plus 0x4800000000001010. The lower four bits selected by 0xe001 correspond to offsets 0,13,14,15 from the first value.

## Permission and validation checks

Missing PID returns 3. Nonzero PID must pass 0x2a8ca0; its nonzero error is returned before credential export. The 0x2ae privilege check chooses full versus filtered output rather than always denying access. With a null output pointer, its status is returned; with a nonnull pointer, successful copyout can return zero even when the full-info privilege check failed. That behavior is visible and consistent with a filtered-query design.

## Data flow and locking

pid -> process lock/visibility -> cred at proc+0x40 -> local zeroed credential_query_record -> full memcpy or authid/capability filter -> process unlock -> optional copyout to uap+8 -> stack-canary verification. Credential contents are copied while the process lock is held.

## Attack surface and limits

Review the nonzero-PID visibility helper, policy for the authid allowlist and retained high capability bits, and lifetime of the credential object under its locking contract. The entire 0x88-byte temporary is zero-initialized, limiting leakage from filtered fields. No hardware/network diagnostic operations occur in this handler. Subsequent string functions are unrelated neighbors.

## Interpretation check

Failure of the full-info privilege check is not an automatic bypass: the machine code deliberately builds a reduced record. A successful filtered copyout must not be reported as full credential disclosure.
