## Behavior and data flow

Validates nonzero pattern and mode fields, optionally copies in a four-byte timeout budget from argument +0x20, and looks up a type-0x110 handle. Calls `0xbaee80(object, pattern, mode, optional_kernel_result, optional_kernel_timeout)`. A requested output pattern is copied out as eight bytes after the operation. Lookup is then released; if timeout was supplied and pattern copyout succeeded, helper `0xbafff0` copies the four-byte updated timeout back. The wait helper’s nonzero status takes priority over copyout errors. Missing handle returns 3; invalid mode/pattern returns 0x16. The raw decompiler emits `halt_baddata` for the tiny timeout-copyout helper because it ends in an unmapped tail jump; assembly establishes that it tail-calls `0x2591d0(...,4)`.

The recovered core converts the timeout using division/modulo 1,000,000 and nanosecond scaling, establishing a **32-bit microsecond** input/remaining budget. It saturates the remaining value at zero and maps the observed timeout result to status 0x3c.

## Dispatch and subcommands

This is one operation in the shared type-0x110 family: create 538, delete 539, open 540, close 541, wait 542, poll 543, signal 544, clear/AND 545 and cancel/reset 546. These operation names are analyst inferences from the code, not recovered symbols.

Mode low bits must equal 1 or 2; bits 0x10 and 0x20 cannot both be set. This wrapper does not reject every other mode bit. The low bits govern matching and the 0x30 group governs post-match clearing in the event helper; exact behavior is shown in the helper pseudocode.

Core matching is explicit: mode 1 requires `(pattern & requested) == requested`; mode 2 requires a nonzero intersection. Mode 0x10 clears the entire pattern after a match; 0x20 clears only requested bits. The observed pattern is captured before this clear.

## Attack surface and limits of conclusions

Waiter insertion/removal, cancellation, timeout accounting and concurrent signal/clear/delete are the core state boundaries. The wrapper performs fixed-size 4/8-byte copies; there is no variable user-controlled transfer length. Output may be attempted even when waiting fails, and an operation failure can supersede an output fault. The microsecond unit is supported by arithmetic in the recovered helper, rather than inferred from the argument width.

This is static analysis of a recorded kernel image. A missing check in this body does not establish that the syscall entry path, object namespace, or external callees impose no checks. Review points are not confirmed vulnerabilities or exploit primitives. No target code was executed.
